# Object Oriented Programming

## Library Kiosk - Manager Display

객체지향 프로그래밍 강의 팀 프로젝트로 진행한 **도서관 키오스크의 관리자 화면** 구현 프로젝트입니다.

도서 정보를 CSV 파일에서 불러와 관리자가 도서 목록을 확인하고 검색할 수 있는 화면을 Java Swing으로 구현했습니다.

## 주요 기능

* CSV 파일 기반 도서 데이터 불러오기
* 도서 목록 테이블 출력
* 도서 검색 기능
* 관리자 화면 UI 구성

## 개발 환경

* Language: Java
* GUI: Java Swing
* IDE: IntelliJ IDEA
* Version Control: Git / GitHub

## 프로젝트 형태

* 객체지향 프로그래밍 강의 팀 프로젝트
* 도서관 키오스크 프로젝트의 관리자 기능을 별도 저장소로 분리하여 관리
* Java의 클래스와 객체를 활용한 기능 구현 및 UI 구성
